# STACKLY RESERVE — Luxury Restaurant Reservations & Haute Gastronomy Platform

An ultra-luxury, high-performance web platform for 3-Star Michelin restaurant reservations, bespoke buyout requests, and Maître D' operations.

## 🚀 Built With
- **HTML5**: Semantic, accessible markup across 11 pages.
- **Vanilla CSS3**: Tailored styling & design tokens (`css/styles.css`).
- **JavaScript (ES6)**: Vanilla JS store, component rendering engine, and page controllers (`js/`).
- **Local WebP Assets**: High-resolution local image library (`assets/`).

## 📁 Directory Structure
```text
├── index.html               # Main Home Landing Page
├── restaurants.html         # Restaurant Catalog & Map Stage
├── restaurant-detail.html   # Restaurant Detail, 2D Floor Plan & Reviews
├── about.html               # Haute Gastronomy Charter & Philosophy
├── concierge.html           # VIP Bespoke Buyout & Support Desk
├── my-reservations.html     # Diner Reservation Management & NFC Pass
├── login.html               # VIP Member & Admin Sign In
├── signup.html              # VIP Member Application
├── client-profile.html      # Gastronome Member Dashboard & Pass Vault
├── admin-dashboard.html     # Maître D' & Operations Console
├── 404.html                 # Custom 404 Error Page
├── css/
│   └── styles.css           # Global Design Tokens & Utilities
├── js/
│   ├── data.js              # Central Restaurants & Experiences Database
│   ├── store.js             # Reactive State Store & Persistence
│   ├── components.js        # Global Navbar, Footer & Modal Generators
│   ├── main.js              # 3-Sec Preloader & Scroll Entrance Animations
│   └── pages/               # Page-specific Controllers
└── assets/                  # Local WebP Media Library
```

## 💻 Running Locally
```bash
npx serve -p 3000 .
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
